# Oasis Infobyte Web Development Internship

This directory contains the projects completed during my one-month web development internship with Oasis Infobyte.

## Internship Overview

During the internship, I practiced building responsive front-end interfaces, browser-based interactions, and a full-stack authentication workflow. The work progressed from small client-side utilities to a Node.js and MongoDB application.

## Projects

### Task 1: Calculator

A responsive calculator interface with arithmetic operations, parentheses, percentages, square roots, answer recall, delete, clear, and sign toggling.

- Technologies: HTML, CSS, JavaScript
- Location: [task1](./task1)
- Run: Open `task1/index.html` in a browser

### Task 2: Cristiano Ronaldo Tribute Page

A responsive tribute page featuring a biography, career timeline, statistics, image gallery, records, and interactive page behavior.

- Technologies: HTML, CSS, JavaScript
- Location: [task2](./task2)
- Run: Open `task2/index.html` in a browser

### Task 3: To-Do List Web App

A task management application that supports adding, editing, completing, deleting, filtering, and clearing tasks.

- Technologies: HTML, CSS, JavaScript
- Location: [task3](./task3)
- Run: Open `task3/index.html` in a browser

### Task 4: Authentication System

A full-stack registration and login application with password hashing, JWT authentication, protected dashboard access, and MongoDB persistence.

- Technologies: HTML, CSS, JavaScript, Node.js, Express, MongoDB, Mongoose, bcryptjs, JSON Web Tokens
- Location: [task4](./task4)
- Run:

```bash
cd task4
npm install
npm run dev
```

The authentication project requires a local MongoDB instance. Configure its values in `task4/.env`, which is intentionally excluded from Git because it contains secrets and local connection settings.

## Skills Practiced

- Semantic HTML and responsive CSS
- DOM manipulation and browser event handling
- Form validation and client-side state management
- Building reusable interactive UI behavior
- REST API development with Express
- Password hashing and JWT-based authentication

This internship gave me practical experience taking web projects from idea to implementation, improving user interfaces, connecting front-end pages to backend services, and applying basic security practices to authentication flows.
